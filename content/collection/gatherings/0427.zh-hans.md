## 第 6 页 · 制度说明首页

> **物理社社费与贡献积分制度说明**
> 社费 · 贡献积分 · 公开监督 · 合规边界

> **核心立场**
> - 让社团活动更稳定
> - 让资金和规则更透明
> - 让制度边界更清晰

四项原则：

| 原则 | 说明 |
| --- | --- |
| **公开透明** | 收入来源、支出用途、凭证与余额可查 |
| **自愿参与** | 缴纳会费不是加入社团的前提 |
| **合规运行** | 社费与积分不越界，不做货币化设计 |
| **社团自治** | 由社内会计与出纳监管，规则提前公布 |

> 依据：社费草案、法律条文与定义、稳定／代币风险建议文档

!!! note "「依据」三份文件"
    本页明确列出了制度设计所依据的三份文件：
    **《社费草案》《法律条文与定义》《稳定／代币风险建议文档》**。

    这三份文件即 `资料/` 中的 [功勋制度草案](../../about/sources/index.md#merit-rules-draft "功勋制度.docx")、[法律条文与定义](../../about/sources/index.md#merit-legal "法律条文与定义.docx")、[稳定 · 讨论材料](../../about/sources/index.md#merit-stability "稳定.docx")。
    按 [白皮书与留存边界](../../system/merit/whitepapers.md) 的公开范围，**本站不公开其内容**。

## 第 7 页 · 为什么需要这套制度

> **为什么需要这套制度**
>
> 制度不是为了「收费」，而是为了解决社团活动运行中的现实问题。

| # | 问题 | 具体表现 |
| --- | --- | --- |
| 1 | **报销时间差** | 学校正式审批和报销需要流程；器材与材料常常需要提前采购；社团需要具备**短期垫付能力** |
| 2 | **活动支出多样** | 实验、竞赛、例会和福利活动都会产生费用；部分支出可能不属于统一报销范围；需要清楚区分资金用途 |
| 3 | **信任与规则** | 社费和积分若规则不清，容易引发误解；账目不透明会造成信任危机；提前建立规则能减少纠纷 |

> 用**制度化方式**保障活动持续开展，而不是用临时办法解决每一次支出。

!!! note "本页的论证结构"
    本页用「三个现实问题 → 一个对比结论」的结构论证制度必要性。
    其中「报销时间差 / 短期垫付能力」是最具体的一条：
    它解释了为什么社团需要**持有现金**，而不只是记账。

## 第 8 页 · 社费资金池设计

> **社费资金池设计**
> 将经费用途分清楚，是后续公开监督和风险控制的基础。

**固定资金池**

- 用于垫付**可报销**的社团支出
- 帮助应对学校审批前的**时间差**
- 强调**凭证留存**与后续核销
- **不应被设计为个人收益来源**

**活动资金池**

- 用于承担部分**不可报销**活动费用
- 如小型材料、活动组织和福利安排
- 支出应与社团活动**直接相关**
- 金额、用途和审批流程需**公开**

> 建议原则：**社费自愿、用途明确、凭证齐全、定期公示。**

!!! warning "「活动资金池」与「流动资金池」的命名差异"
    本页第二个池子名为「**活动资金池**」；
    而 `物理社功勋系统资金流转白皮书` 与 `会员公开白皮书` 中名为
    「**流动资金池**」，且定义为「进入会员个人账户、可用于社团内部活动和资源使用的部分」。

    两者职责描述接近但不等同：本页强调「不可报销费用」，
    白皮书强调「计入个人账户」。并列保留。

## 第 9 页 · 贡献积分的定位

> **贡献积分的定位**
> 积分可以记录贡献，但**绝不能被包装成货币、投资或收益凭证**。

| 它应该是 | 它不应该是 |
| --- | --- |
| ✓ 社团内部贡献记录 | ✕ 货币、代币或通证 |
| ✓ 活动参与激励工具 | ✕ 投资或融资工具 |
| ✓ 福利活动权益记录 | ✕ 固定收益或分红承诺 |
| ✓ 社团自治辅助机制 | ✕ 可转让、交易、折现的凭证 |

!!! note "本页是整套制度的合规底线"
    右侧四条的措辞（「绝不能被包装成」）是本套演示文稿中**语气最强的一页**。
    它把积分与「货币 / 投资 / 收益凭证」三类事物做了切割，
    与 [法律条文与定义](../../about/sources/index.md#merit-legal "法律条文与定义.docx") 中对代币发行融资与非法集资「四性」的分析互为对应。

## 第 10 页 · 积分如何获得与使用

> **积分如何获得与使用**
> 积分应围绕**真实贡献**产生，规则必须**提前公布**。

| 来源 | 举例 |
| --- | --- |
| **参与** | 例会听讲、参与实验、参加社团活动 |
| **贡献** | 讲解题目、协助组织、完成社团任务 |
| **表现** | 竞赛获奖、大型活动突出贡献 |
| **记录** | 形成公开规则下的贡献积分 |

> **使用边界**
> - 仅限社团内部福利活动或权益记录
> - **不得转让、交易、折现或承诺经济回报**
> - **不得用积分制造「投入越多收益越高」的预期**

!!! note "「不得制造预期」"
    第三条边界是本页最特殊的一条：它限制的不是行为，而是**预期的形成**。
    这与第 9 页「不是投资工具」在逻辑上互补。

## 第 11 页 · 争议处理机制

> **争议处理机制**
> 规则越清晰，越能保护**社员、社团干部和指导老师**。

四步流程：

| 步骤 | 动作 |
| --- | --- |
| 1 **提交申请** | 社员提出书面申请并说明原因 |
| 2 **审核记录** | 按制度审核，留存时间、金额和依据 |
| 3 **结果回馈** | 告知处理结果，必要时公示规则依据 |
| 4 **申诉说明** | 成员可提出异议、补充说明或申请复核 |

**器材损坏处理**

- 应依据**事实、证据和章程条款**处理
- **不建议用简单扣积分替代正式赔偿**
- 应保留**说明、协商和申诉空间**

**避免霸道条款**

- 减少「**最终解释权归社团所有**」的单向表达
- 改为「**按章程解释，接受监督与申诉**」
- 处理结果应**可追溯、可说明**

!!! note "本页值得单独指出的一点"
    「避免霸道条款」这一小节**主动限制社团自身的权力**，
    并要求以「按章程解释，接受监督与申诉」替代「最终解释权归社团所有」。
    这在学生社团的制度文本中并不常见。

## 第 12 页 · 公开账本与知情权

> **公开账本与知情权**
> 透明不是负担，而是**减少误会和保护社团干部**的机制。

| 层次 | 内容 |
| --- | --- |
| **公开账本** | 凭证 · 流向 · 余额 |
| **整体收支** | 公开收入来源；公开支出用途；定期汇总公示 |
| **个人记录** | 本人社费记录；本人积分记录 |
| **原始凭证** | 支付截图；发票或收据；采购清单 |
| **监督机制** | 社员查询；老师指导；问题申诉 |

!!! note "透明被论证为对干部的保护"
    副标题把「透明」定义为**保护社团干部**的机制，而不只是约束他们。
    这一视角与常见的「透明是为了监督」不同。

## 第 13 页 · 执行落地流程

> **执行落地流程**
> 建议**先试行、再修订**，避免制度一开始就过重或过急。

| 步骤 | 动作 |
| --- | --- |
| 1 **公开草案** | 向社员与老师说明制度目的，集中收集意见 |
| 2 **修订细则** | 明确社费、积分、监督和争议处理规则 |
| 3 **建立账本** | 统一记录收支、凭证、个人记录和公示周期 |
| 4 **定期复盘** | 每月或每学期检查执行效果并修订问题 |

!!! note "「先试行、再修订」"
    本页明确了制度**不是一次性定稿**，而是把修订机制写进了流程本身（第 4 步）。
    这与 `功勋系统` 后续出现 v1.0 → 正式版第一版 → 会员公开版的
    多版本演进相印证。
