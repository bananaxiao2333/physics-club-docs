# 数据隐私

<p class="memorial-kicker">DATA &amp; PRIVACY · 三种语言并列</p>

这一页三种语言并列写出，内容相同。它不是法律文书，只是一句能兑现的话：
**本站不收集任何使用信息。**

<div class="grid" markdown>

<div markdown>
### 简体中文

**不收集使用信息。** 本站没有任何统计分析、没有埋点、没有广告、没有第三方跟踪脚本。
没有人能看到你读过哪一页、停留多久、从哪里来。

**不使用 cookie。** 页面不写任何 cookie。唯一会写进浏览器本地存储的，是你在
深浅色之间选的偏好（键名以本站路径开头，只存在你自己的浏览器里），
用来避免每次打开都恢复成默认配色。清除浏览器数据即可抹掉。

**不向第三方发起请求。** 页面的字体、样式与脚本全部与本站同源托管。
字体是 Inter 与 JetBrains Mono 的 latin 子集，放在 `assets/fonts/` 下；
没有 Google Fonts、没有 CDN、没有外链脚本。因此打开任意一页，
你的浏览器只会联系本站一个域名。

**关于服务器日志。** 本站托管在 GitHub Pages。托管方会按常规保留访问日志
（IP、时间、User-Agent 之类），这是服务器运作的固有部分；我们无权访问这些日志，
也没有用它们做过任何事。

**下载的文件。** 「功勋系统」等页面提供的 `.docx`、`.pdf` 是留存原件的原样副本，
其中可能含有当时制作时留下的文档属性。下载由你的浏览器直接完成，不经过任何中间服务。
</div>

### English

**No usage data is collected.** This site has no analytics, no tracking pixels, no
advertising, and no third-party scripts. No one can see which page you read, how long
you stayed, or where you came from.

**No cookies.** The site sets no cookies. The only thing written to browser local
storage is your light/dark preference (keyed under this site's path, stored only in
your own browser), so the palette does not reset on every visit. Clearing your browser
data removes it.

**No third-party requests.** Fonts, styles and scripts are all served from this site's
own origin. The typefaces are the Latin subsets of Inter and JetBrains Mono, kept under
`assets/fonts/` — no Google Fonts, no CDN, no external scripts. Opening any page contacts
one domain only: this one.

**About server logs.** This site is hosted on GitHub Pages. The host keeps ordinary access
logs (IP, time, User-Agent and the like) as an inherent part of serving HTTP. We have no
access to those logs and have never used them for anything.

**Downloaded files.** The `.docx` and `.pdf` files offered on pages such as the merit-system
record are byte-for-byte copies of the surviving originals, and may carry document metadata
from when they were made. Downloads go directly from your browser — no intermediary.

## 为什么写这一页

因为「不收集」这句话，只有在能被核对的时候才值得相信。上面每一条都可以自己验证：

1. 打开浏览器的开发者工具，切到 Network 面板，刷新任意一页——
   所有请求都指向本站这一个域名。
2. 在 Application 面板里查看 Local Storage 与 Cookies——
   只有一条配色偏好，没有 cookie。
3. 阅读本站的源码与构建配置：本站是公开的静态站点，
   构建产物里没有统计脚本。

如果哪天这一页说的和实际不符，那是本站的错，请指出来。
