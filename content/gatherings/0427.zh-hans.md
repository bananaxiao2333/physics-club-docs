## 第 6 页 · 制度說明首頁

> **物理社社費與貢獻積分制度說明**
> 社費 · 貢獻積分 · 公開監督 · 合規邊界

> **核心立場**
> - 讓社團活動更穩定
> - 讓資金和規則更透明
> - 讓制度邊界更清晰

四项原则：

| 原则 | 说明 |
| --- | --- |
| **公開透明** | 收入来源、支出用途、凭证与余额可查 |
| **自願參與** | 缴纳会费不是加入社团的前提 |
| **合規運行** | 社费与积分不越界，不做货币化设计 |
| **社團自治** | 由社内会计与出纳监管，规则提前公布 |

> 依據：社費草案、法律條文與定義、穩定／代幣風險建議文檔

!!! note "「依據」三份文件"
    本页明确列出了制度设计所依据的三份文件：
    **《社費草案》《法律條文與定義》《穩定／代幣風險建議文檔》**。

    这三份文件即 `资料/` 中的 `功勋制度.docx`、`法律条文与定义.docx`、`稳定.docx`。
    按 [白皮书与留存边界](../merit/whitepapers.md) 的公开范围，**本站不公开其内容**。

## 第 7 页 · 為什麼需要這套制度

> **為什麼需要這套制度**
>
> 制度不是為了「收費」，而是為了解決社團活動運行中的現實問題。

| # | 问题 | 具体表现 |
| --- | --- | --- |
| 1 | **報銷時間差** | 學校正式審批和報銷需要流程；器材與材料常常需要提前採購；社團需要具備**短期墊付能力** |
| 2 | **活動支出多樣** | 實驗、競賽、例會和福利活動都會產生費用；部分支出可能不屬於統一報銷範圍；需要清楚區分資金用途 |
| 3 | **信任與規則** | 社費和積分若規則不清，容易引發誤解；賬目不透明會造成信任危機；提前建立規則能減少糾紛 |

> 用**制度化方式**保障活動持續開展，而不是用臨時辦法解決每一次支出。

!!! note "本页的论证结构"
    本页用「三个现实问题 → 一个对比结论」的结构论证制度必要性。
    其中「報銷時間差 / 短期墊付能力」是最具体的一条：
    它解释了为什么社团需要**持有现金**，而不只是记账。

## 第 8 页 · 社費資金池設計

> **社費資金池設計**
> 將經費用途分清楚，是後續公開監督和風險控制的基礎。

**固定資金池**

- 用於墊付**可報銷**的社團支出
- 幫助應對學校審批前的**時間差**
- 強調**憑證留存**與後續核銷
- **不應被設計為個人收益來源**

**活動資金池**

- 用於承擔部分**不可報銷**活動費用
- 如小型材料、活動組織和福利安排
- 支出應與社團活動**直接相關**
- 金額、用途和審批流程需**公開**

> 建議原則：**社費自願、用途明確、憑證齊全、定期公示。**

!!! warning "「活動資金池」与「流動資金池」的命名差异"
    本页第二个池子名为「**活動資金池**」；
    而 `物理社功勋系统资金流转白皮书` 与 `会员公开白皮书` 中名为
    「**流動資金池**」，且定义为「進入會員個人帳戶、可用於社團內部活動和資源使用的部分」。

    两者职责描述接近但不等同：本页强调「不可報銷費用」，
    白皮书强调「计入个人账户」。并列保留。

## 第 9 页 · 貢獻積分的定位

> **貢獻積分的定位**
> 積分可以記錄貢獻，但**絕不能被包裝成貨幣、投資或收益憑證**。

| 它應該是 | 它不應該是 |
| --- | --- |
| ✓ 社團內部貢獻記錄 | ✕ 貨幣、代幣或通證 |
| ✓ 活動參與激勵工具 | ✕ 投資或融資工具 |
| ✓ 福利活動權益記錄 | ✕ 固定收益或分紅承諾 |
| ✓ 社團自治輔助機制 | ✕ 可轉讓、交易、折現的憑證 |

!!! note "本页是整套制度的合规底线"
    右侧四条的措辞（「絕不能被包裝成」）是本套演示文稿中**语气最强的一页**。
    它把积分与「货币 / 投资 / 收益凭证」三类事物做了切割，
    与 `法律条文与定义.docx` 中对代币发行融资与非法集资「四性」的分析互为对应。

## 第 10 页 · 積分如何獲得與使用

> **積分如何獲得與使用**
> 積分應圍繞**真實貢獻**產生，規則必須**提前公佈**。

| 来源 | 举例 |
| --- | --- |
| **參與** | 例會聽講、參與實驗、參加社團活動 |
| **貢獻** | 講解題目、協助組織、完成社團任務 |
| **表現** | 競賽獲獎、大型活動突出貢獻 |
| **記錄** | 形成公開規則下的貢獻積分 |

> **使用邊界**
> - 僅限社團內部福利活動或權益記錄
> - **不得轉讓、交易、折現或承諾經濟回報**
> - **不得用積分製造「投入越多收益越高」的預期**

!!! note "「不得製造預期」"
    第三条边界是本页最特殊的一条：它限制的不是行为，而是**预期的形成**。
    这与第 9 页「不是投资工具」在逻辑上互补。

## 第 11 页 · 爭議處理機制

> **爭議處理機制**
> 規則越清晰，越能保護**社員、社團幹部和指導老師**。

四步流程：

| 步骤 | 动作 |
| --- | --- |
| 1 **提交申請** | 社員提出書面申請並說明原因 |
| 2 **審核記錄** | 按制度審核，留存時間、金額和依據 |
| 3 **結果回饋** | 告知處理結果，必要時公示規則依據 |
| 4 **申訴說明** | 成員可提出異議、補充說明或申請復核 |

**器材損壞處理**

- 應依據**事實、證據和章程條款**處理
- **不建議用簡單扣積分替代正式賠償**
- 應保留**說明、協商和申訴空間**

**避免霸道條款**

- 減少「**最終解釋權歸社團所有**」的單向表達
- 改為「**按章程解釋，接受監督與申訴**」
- 處理結果應**可追溯、可說明**

!!! note "本页值得单独指出的一点"
    「避免霸道條款」这一小节**主动限制社团自身的权力**，
    并要求以「按章程解釋，接受監督與申訴」替代「最終解釋權歸社團所有」。
    这在学生社团的制度文本中并不常见。

## 第 12 页 · 公開帳本與知情權

> **公開帳本與知情權**
> 透明不是負擔，而是**減少誤會和保護社團幹部**的機制。

| 层次 | 内容 |
| --- | --- |
| **公開帳本** | 憑證 · 流向 · 餘額 |
| **整體收支** | 公開收入來源；公開支出用途；定期匯總公示 |
| **個人記錄** | 本人社費記錄；本人積分記錄 |
| **原始憑證** | 支付截圖；發票或收據；採購清單 |
| **監督機制** | 社員查詢；老師指導；問題申訴 |

!!! note "透明被论证为对干部的保护"
    副标题把「透明」定义为**保护社团干部**的机制，而不只是约束他们。
    这一视角与常见的「透明是为了监督」不同。

## 第 13 页 · 執行落地流程

> **執行落地流程**
> 建議**先試行、再修訂**，避免制度一開始就過重或過急。

| 步骤 | 动作 |
| --- | --- |
| 1 **公開草案** | 向社員與老師說明制度目的，集中收集意見 |
| 2 **修訂細則** | 明確社費、積分、監督和爭議處理規則 |
| 3 **建立帳本** | 統一記錄收支、憑證、個人記錄和公示週期 |
| 4 **定期複盤** | 每月或每學期檢查執行效果並修訂問題 |

!!! note "「先試行、再修訂」"
    本页明确了制度**不是一次性定稿**，而是把修订机制写进了流程本身（第 4 步）。
    这与 `功勋系统` 后续出现 v1.0 → 正式版第一版 → 会员公开版的
    多版本演进相印证。
