## 筹备期（活动前 3 周 — 前 1 天）

### 活动前 3 周

1. 总负责人敲定活动最终方案、整体预算，完成学校审批、场地／设备申请
2. 统筹执行组整理活动全流程文档，明确小组分工，统计参赛报名信息

### 活动前 2 周

1. 后勤保障组汇总物料需求，整理采购清单并完成审核
2. 宣传摄制组制作预热海报、折法图纸、打卡墙、预热推文，发布至校园各渠道
3. 赛事运营设计组制定比赛规则／评分标准，搭建报名通道，解答选手疑问

### 活动前 1 周（周一）

1. 总负责人完成 **3 位校长**及参与教师的邀请对接
2. 赛事运营设计组统计报名信息、完成选手分组，制作赛程表／计分表／号码牌
3. 赛事运营设计组开展裁判、测距员、记录员岗前培训
4. 后勤保障组完成所有物料采购，建立台账分类保管

### 活动前 1 天

1. 后勤保障组 + 现场执行组完成场地分区布置、划线，调试激光测距仪等设备
2. 总负责人 + 副社长组织全体工作人员开展全流程彩排，模拟突发状况处理
3. 各小组召开内部会议，再次明确次日岗位职责及工作要求
4. 后勤保障组将物料全部分发到位，完成最终清点

## 活动当天 · 上午场（室内体育馆 08:00–12:30）

### 08:00–08:40 全员到岗准备

1. 各小组组长确认人员到岗、物料到位、设备正常
2. 对激光测距仪、打卡墙等关键设备／物料进行二次调试
3. 再次明确各岗位应急处理方案

### 09:00–10:30 全民折纸与自由飞行

1. 现场执行组开放签名打卡区，引导师生签名、拍照、粘贴心愿贴
2. **胡益成、肖子扬**在教学角在岗，手把手教学 **6 种**纸飞机折法，发放图纸
3. 现场执行组分岗维护自由飞行区、距离挑战区、创意展示区秩序
4. 距离挑战区达标学生，由后勤保障组即时发放达标奖
5. 宣传摄制组全程跟拍，实时剪辑短视频并同步校园渠道
6. 后勤保障组全场巡查，及时补充 A4 纸、奖品、文具等物料
7. 后勤保障组快速处理现场设备临时故障
8. 总负责人 + 副社长全场巡场，协调突发状况，对接到场嘉宾
9. 总负责人 + 副社长引导师生开展互动，营造活动氛围

### 10:30–11:30 工程组展示与测试

1. 赛事运营设计组 1 人主持，2 人负责裁判 + 测距，1 人记录并公示成绩
2. 赛事运营设计组 1 人发放奖品，3 人维持现场秩序
3. 现场执行组 3 人引导学生有序围观，同步讲解测试规则
4. 宣传摄制组拍摄测试高光时刻，记录各队伍成绩，准备下午开场视频素材

### 11:30–12:00 全校竞猜活动

1. 现场执行组完成竞猜券的发放与回收工作
2. 现场执行组将回收竞猜券封存至投票箱
3. 统筹执行组在现场公示竞猜开奖规则及开奖时间
4. 统筹执行组引导学生有序参与竞猜，解答相关疑问

### 12:00–12:30 上午场收尾 + 短复盘

1. 后勤保障组回收各分区物料，清点剩余物资，简易整理场地
2. 赛事运营设计组整理上午测试成绩，确认下午参赛选手到场情况
3. 宣传摄制组整理上午拍摄素材，完成下午开场回顾视频剪辑
4. 总负责人 + 副社长组织核心团队，召开 **10 分钟**简短复盘会
5. 针对上午工作问题，即时调整下午工作安排及人员分工

## 活动当天 · 下午场（大操场 13:30–16:00）

### 12:30–14:00 赛前最终准备

1. 全体工作人员到岗，各小组组长确认物料、设备、场地状态
2. 现场执行组完成操场飞行区隔离带设置，划分**两片飞行场地**

### 14:20–15:20 正式飞行比赛

1. **小组赛**：参赛人员 1 次预飞 + **3 次**正式飞行，取最佳成绩选出 **8 强**
2. **8 强决赛**：8 强选手 **5 次**飞行，叠加小组赛成绩取最佳，决出冠亚季军及**校园纪录保持者**
3. **师生挑战赛**：学生组别自主对接教师竞赛，教师可使用物理社器材，**胜败均发奖**
4. 特邀 **sink** 担任**总裁判长**，负责规则解读、争议最终判定
5. 赛事运营设计组 1 人主持，把控比赛节奏，播报选手信息及成绩
6. 赛事运营设计组 2 人负责选手检录，3 人担任飞行裁判监督飞行过程
7. 赛事运营设计组 3 人负责激光测距，精准记录飞行数据
8. 赛事运营设计组 2 人计分并**实时投屏公示**，确保公开透明
9. 赛事运营设计组 2 人维护比赛区域秩序，禁止无关人员进入飞行区
10. 宣传摄制组全程跟拍比赛高光时刻，记录颁奖素材
11. 总负责人 + 副社长全场把控节奏，对接评委嘉宾，处理突发争议

!!! note "赛制存在第二个版本"
    `资料/飞行节分工安排 2.docx` 记载的是 **1 次预飞 + 2 次正式飞行**、
    8 强决赛 **3 次**飞行。两份原始件不一致，此处并列保留、不合并。
    见 [资料出处](../sources/index.md)。

### 15:20–15:40 颁奖仪式 + 校园纪录发布

1. 统筹执行组对接颁奖嘉宾（校长／教师），引导嘉宾上台
2. 统筹执行组把控颁奖顺序及流程，保障仪式顺畅
3. 赛事运营设计组发布本届**校园纸飞机飞行纪录**，公示最终获奖名单
4. 赛事运营设计组按奖项分类摆放证书、奖牌、奖品，配合颁奖
5. 现场执行组完成竞猜幸运奖开奖，核对中奖学生名单
6. 现场执行组引导中奖学生有序领奖，解答领奖相关问题
7. 宣传摄制组全程拍摄颁奖画面，记录高光时刻

### 15:40–16:00 下午场全场收尾

1. 全体工作人员共同清理场地，做到桌椅归位、垃圾清运
2. 后勤保障组清点所有物料、设备，核对数量并做好记录
3. 后勤保障组即时归还向学校借用的所有物资
4. 总负责人 + 副社长组织全体工作人员召开简短总结会，感谢工作付出

## 收尾复盘期（活动后 1 周内）

### 活动后 24 小时内

1. 宣传摄制组完成活动回顾推文、短视频的制作与发布
2. 宣传摄制组整理所有拍摄素材，按类别分类归档
3. 宣传摄制组提交活动传播数据复盘报告

### 活动后 3 天内

1. 赛事运营设计组在校园内公示最终获奖名单及校园纪录
2. 赛事运营设计组完成校园纪录展板的制作与摆放
3. 后勤保障组完成剩余物料的盘点入库，做好台账记录
4. 后勤保障组核对经费使用情况，提交最终财务报表及报销材料

## 核心奖项设置

### 上午场 · 达标奖

**无名额限制。** 学生在距离挑战区达到 **10 米 / 20 米 / 30 米**任意挑战线，即时领取对应奖品。

### 下午场 · 正式奖项

| 奖项 | 名额 | 评选方式 |
| --- | --- | --- |
| 竞技核心奖 · 冠军 | 1 名 | 按正式比赛飞行距离评选 |
| 竞技核心奖 · 亚军 | 2 名 | 按正式比赛飞行距离评选 |
| 竞技核心奖 · 季军 | 3 名 | 按正式比赛飞行距离评选 |
| 校园纪录保持者 | 1 名 | 本次活动飞行距离最远者 |
| 最佳创意纸飞机奖 | 一等 1 / 二等 3 / 三等 5 | 全校投票 + 评委评选 |
| 师生互动人气奖 | 3 名 | 参与师生挑战赛互动最多、人气最高的学生组别 |
| 竞猜幸运奖 | **30 名** | 从竞猜命中的学生中随机抽取 |
| 优秀志愿者奖 | 若干名 | 从工作人员中评选表现突出者 |

!!! note "竞猜幸运奖名额有两个版本"
    执行流程文档写 **30 名**，分工安排文档写 **不限名**。此处并列保留。

分组**最多六人**，按组颁奖。
