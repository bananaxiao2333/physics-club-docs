## 编后说明

### 内容依据

本站依据上述材料整理。**页面中的抒情文字为纪念站编写**，不作为历史人物原话；
引用集会原稿处，均标注材料出处。

### 照片与视觉素材

照片来自 `资料/微信assets`；纸飞机图、场地图与海报来自同一资料目录或演示文稿提取。
图片经过适合网页浏览的尺寸与格式优化。**未使用网络示意图冒充社团活动。**
