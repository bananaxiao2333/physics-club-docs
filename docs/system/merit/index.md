# 功勋系统

<p class="memorial-kicker">LATE STAGE · THE MERIT SYSTEM</p>

    并明确给出了本站应采用的三层公开边界。

> 功勋系统是物理社后期尝试建立的一套内部会费、活动、贡献和奖励记录机制。
> 它最初源于对社费透明、活动核算和成员贡献记录的需求，后来逐步发展为包含
> 固定资金池、流动资金池、个人账户、公开账本和奖励池的电子系统。
>
> 在这个系统中，成员缴费、参加活动、领取物资、获得奖励和申请退款都会留下记录。
> **系统并不只是为了算账，更是为了让社团运转过程可被看见，让积极参与的人留下痕迹。**
>
> 虽然物理社已经解散，功勋系统仍然是这段历史中一项重要的组织实验。
> 它代表了物理社成员曾经对透明、公平、制度和长期运作的认真尝试。

## 为什么会出现这套系统

功勋系统的出现，源于物理社在实际运作中面临的几个具体问题：

- 会费如何清楚记录
- 活动费用如何核算
- 公共资金如何透明
- 积极参与者如何被看见
- 奖励如何发放
- 成员如何查询自己的余额和历史记录

原始设想并非单纯做一个电子表格，而是希望建立一套较完整的内部记录系统：
会员缴纳会费后，系统形成对应记录；社团发生消费、活动、奖励和结算时，
系统同步留下账目；成员可以查看自己的账户与公开账本。

核心诉求是三点：**透明 · 可追溯 · 可持续**。

## 基本定位

在最终公开表达中，功勋被定位为物理社内部的**会费与贡献记录工具**，
用于记录会员缴纳、活动使用、公共支出、奖励发放和账户变动。

制度反复强调的边界：

!!! warning "功勋不是货币"
    功勋只在社团内部规则下使用，**不面向社团外部人员开放，不作为对外支付工具，
    不提供会员之间的自由转让、买卖、折现或其他外部流通功能**。

    这一边界在多个白皮书版本中被保留下来，是整套设计的合规底线。

## 要解决的真实问题

| 环节 | 系统的作用 |
| --- | --- |
| 缴费 | 每笔入账留下金额、时间、经办人、审核状态与凭证 |
| 活动 | 收入、成本、扣减与结余形成项目记录 |
| 物资 | 领取与结算可核对，差额有去向 |
| 奖励 | 由奖池经多签确认后发放，有明确原因与审核记录 |
| 退款 | 与账户注销或退会绑定，真实资金流出并核销 |
| 查询 | 会员可查看本人明细与社团公开账本 |

## 它最终不只是一个软件项目

> 从史料角度看，它体现了一个学生社团试图解决真实问题的过程：
> 会费不透明如何解决，活动成本如何核算，公共资金如何留存，
> 积极成员如何被奖励，系统如何避免失真，
> 会计部门如何从手工记账转向审计监督。

发布演讲里最具代表性的一句话是：

> 物理社不只是一个一起玩物理的地方，
> 也要成为一个**有规则、有账本、有贡献记录、有长期生命力**的社团。
