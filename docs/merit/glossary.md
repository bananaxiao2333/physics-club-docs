# 术语表

<p class="memorial-kicker">GLOSSARY</p>

以下解释采用 `资料/物理社功勋系统对话史料整理_纪念网站版.docx` 附录 B 的**纪念版口径**，
以会员侧理解为主，不涉及后台内部执行参数。

功勋
:   物理社内部会费、活动、贡献和奖励的记录单位。

固定资金池
:   由社团统一管理，用于公共运营、活动支持和奖励来源的资金池。

流动资金池
:   进入会员个人账户、可用于社团内部活动和资源使用的部分。

总账户
:   记录社团整体资金池变化的总账。

个人账户
:   记录单个会员入账、使用、奖励、余额和退款状态的账户。

奖励池
:   从活动盈利或固定资金池中划定、经多签后可向成员发放的奖励额度。

项目待结算
:   活动、食品、材料包等项目从收入到成本核销之间的中间状态。

grant 多签
:   至少三名管理员确认后，奖池才可正式发放。


## 功勋可以做什么

按会员公开白皮书，功勋可在社团规则内用于：

| 场景 | 常见说明 |
| --- | --- |
| 活动费用 | 实验活动、讲座材料、比赛报名或活动组织费用 |
| 实验材料 | 耗材包、电子元件、工具配件、实验小件等 |
| 食品与集体采购 | 活动期间统一订购食品、饮品或其他公共用品 |
| 社团周边 | 徽章、贴纸、记录本、纪念品等 |
| 其他事项 | 以活动说明、系统公告或管理团队确认的规则为准 |

## 功勋不能做什么

!!! warning "使用边界"
    | 不能 | 说明 |
    | --- | --- |
    | 会员之间自由转让 | 不支持 |
    | 私下买卖 | 不支持 |
    | 用于社团外交易 | 不支持 |
    | 随时部分提现 | 不支持；退款原则上与账户注销或退会绑定 |

    任何绕过系统、私下交易或利用漏洞获取功勋的行为，都可能导致账户限制或社团处理。

## 会员的权利

| 权利 | 内容 |
| --- | --- |
| 知情权 | 查看本人账户余额、入账明细、使用明细、奖励明细与退会处理记录 |
| 查阅公开账本 | 查看社团公开账本及本人相关明细（敏感信息按规则脱敏或分级展示） |
| 申诉与复核 | 对记录、扣款、奖励或退款有异议时，可提出申诉或申请复核 |
