## 物理之外，是自由探索的我們

ASJ 英東物理社曾希望創造一個平臺：**讓學生用自己的方式理解物理、表達物理、實踐物理。**

這裡收藏了它留下的講稿、活動方案、設計與影像。社團已經不復存在，但那些認真做過的事，值得被記住。
