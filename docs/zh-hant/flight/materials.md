### 兩件關鍵器材

!!! info inline end "測距儀規格"

    500 m 量程 · ¥159 · 採購 1 件

**激光測距儀（500 m，¥159）** —— 全場單價最高、用途唯一的一件。
它的存在直接對應 [04.27 集會](../collection/gatherings/0427.md) 確立的成績口徑：

> 以**起點和紙飛機落點之間的直線距離**為最終成績

直線距離要求可復現、可爭議時覆核的測量方式，這是採用激光測距而非皮尺的原因。

**定製簽名版（2.3 m × 3.5 m，¥158）** —— 面積約 **8.05 m^2^**，
是清單中唯一需要定製生產的物料，單價僅次於測距儀。

    上表右列有 **7 項**在採購表中找不到對應條目。

    本站不作推斷。

## 現場表單

賽事準備了 **3 份**空白表單，均為繁體中文，**沒有任何填寫記錄**。

=== "報名表"

    > **紙飛機挑戰賽 報名表**

    | 欄目 | 說明 |
    | --- | --- |
    | 組名 | 參賽小組名稱 |
    | 組成員 | 附示例「例如：10S胡益成」 |

    !!! note "示例中的班級編碼"
        示例「**10S**胡益成」中的 `10S` 是班級編碼，
        與 [05.12 分組表](../collection/gatherings/0512.md) 中使用的編碼體系一致
        （10S / 10V / 10G / 10Z / 10J / 10A / 10H / 10K / 9V / 9Z / 7V）。

=== "成績表"

    > **紙飛機挑戰賽 成績表**

    | 欄目 | 說明 |
    | --- | --- |
    | 時間 | 記錄時刻 |
    | 選手編號 | 選手編號 |
    | 比賽成績（距離/米） | 成績，單位為**米** |
    | 測量員 | 測距員簽名 |
    | 記錄員 | 記錄員簽名 |

    !!! note "雙人簽核"
        每一條成績都要求 **測量員與記錄員分別簽名**，
        這與執行流程中「3 人負責激光測距」「2 人計分並實時投屏公示」
        的崗位設置相對應。

    表單為**兩聯重複版式**，可並排記錄兩組。

=== "簽到表"

    > **紙飛機挑戰賽 簽到表**

    | 欄目 | 說明 |
    | --- | --- |
    | 時間 | 到場時刻 |
    | 組名 | 小組名稱 |
    | 人數 | **4–6 人**（表格內直接印有此限值） |
    | 參與者（備註班級） | 參與者姓名，備註班級 |
    | 編號（工作人員填寫） | 工作人員填寫編號 |

    !!! warning "「4–6 人」與其他材料衝突"
        簽到表的表頭印有「==4-6人==」；
        而集會宣傳稿寫「以小組報名 人數 ==2-6 人==」；
        執行流程文檔寫「分組==最多六人==」。

        三個版本並列保留，本站不合併。

### 三份表單的共同點

| 特徵 | 說明 |
| --- | --- |
| 全部空白 | 無任何實際填寫記錄 |
| 全部繁體 | 與集會演示文稿一致 |
| 均有「時間」列 | 說明設計上要求**逐條記錄時刻** |
| 均無人名 | 只有欄目，沒有預設名單 |

!!! quote "由此可以確認的一件事"
    **飛行節的最終賽果在留存材料中沒有記錄。**

    三份表單全部為空白模板，本站因此不公布任何名次、
    距離成績或「校園紀錄」數值。
