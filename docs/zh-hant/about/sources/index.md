## 編後說明

### 內容依據

本站依據上述材料整理。**頁面中的抒情文字為紀念站編寫**，不作為歷史人物原話；
引用集會原稿處，均標註材料出處。

### 照片與視覺素材

照片來自 [現場照片原圖](index.md#photo-assets)；紙飛機圖、場地圖與海報來自同一資料目錄或演示文稿提取。
圖片經過適合網頁瀏覽的尺寸與格式優化。**未使用網絡示意圖冒充社團活動。**

### 材料之間的時間口徑衝突 { #time-conflicts }

留存材料對飛行節的時間存在**四個不同版本**，本站並列保留，不推定最終執行結果：

| 出處 | 時間口徑 |
| --- | --- |
| 4.21 集會定稿 | 4 月 30 日 **14:00–16:30** |
| 飛行節分工安排 | 4 月 30 日 **14:00–16:30**（分項延伸至 17:30） |
| 4.27 集會說明 | 改為 **15:20–16:20** |
| 海報原稿 | **15:00–16:10** |
| 執行流程文檔 | **全天**：上午體育館 08:00–12:30 + 下午大操場 13:30–16:00 |

### 無法確認的事項

!!! warning "本站不補寫的內容"
    - **社團終止日期與原因** —— 材料不能確認，本站不補寫。
    - **飛行節的最終賽果** —— 留存材料只有籌備文件與空白表單（成績表、簽到表均未填寫），**沒有任何實際成績記錄**。
    - **競賽參賽人數** —— 材料可確認「獲獎率 100%」，但**未見參賽人數的原始記載**。
