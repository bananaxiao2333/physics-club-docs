# 關於本站

<p class="memorial-kicker">SOURCES &amp; EDITORIAL NOTES</p>

## 這份記述是怎麼來的

本站**不使用任何二手轉述**。每一處事實都應當在 `资料/` 原始件中核對得到。
這一部分交代兩件事：**材料從哪裡來**，以及**編者做了哪些取捨**。

| [致謝與後記](thanks/index.md) | 特别致謝，以及記述口徑與保留取捨的說明 |

## 記述原則

留存的材料並不完整：有的日期只寫到月份，有的活動只有一句提及，
有的制度留在草案階段。面對這些缺口，本站的取捨是：

- **不補寫**未知的原因、日期與結果；材料到哪一步，正文就寫到哪一步；
- 材料之間口徑不一致時**並列保留各版本**，不推定最終執行結果；
- 過期目錄中的草案**僅作草案**存檔；
- 逐字引用的內容保留原文用字，包括繁體中文原稿。
