## 記述原則

留存的材料並不完整：有的日期只寫到月份，有的活動只有一句提及，
有的制度留在草案階段。面對這些缺口，本站的取捨是：

- **不補寫**未知的原因、日期與結果；材料到哪一步，正文就寫到哪一步；
- 材料之間口徑不一致時**並列保留各版本**，不推定最終執行結果；
- 過期目錄中的草案**僅作草案**存檔；
- **全站一律用通行簡體**，包括引文、人名與組名。原始件多為繁體，
  本站按字形轉寫，不改用字、標點與語序；選用繁體或英文的讀者各得其所。
