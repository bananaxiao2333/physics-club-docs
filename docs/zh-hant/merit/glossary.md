# 術語表

<p class="memorial-kicker">GLOSSARY</p>

以下解釋採用 `资料/物理社功勋系统对话史料整理_纪念网站版.docx` 附錄 B 的**紀念版口徑**，
以會員側理解為主，不涉及後臺內部執行參數。

| 術語 | 紀念版解釋 |
| --- | --- |
| **功勳** | 物理社內部會費、活動、貢獻和獎勵的記錄單位。 |
| **固定資金池** | 由社團統一管理，用於公共運營、活動支持和獎勵來源的資金池。 |
| **流動資金池** | 進入會員個人賬戶、可用於社團內部活動和資源使用的部分。 |
| **總賬戶** | 記錄社團整體資金池變化的總賬。 |
| **個人賬戶** | 記錄單個會員入賬、使用、獎勵、餘額和退款狀態的賬戶。 |
| **獎勵池** | 從活動盈利或固定資金池中劃定、經多簽後可向成員發放的獎勵額度。 |
| **項目待結算** | 活動、食品、材料包等項目從收入到成本核銷之間的中間狀態。 |
| **grant 多簽** | 至少三名管理員確認後，獎池才可正式發放。 |

## 功勳可以做什麼

按會員公開白皮書，功勳可在社團規則內用於：

| 場景 | 常見說明 |
| --- | --- |
| 活動費用 | 實驗活動、講座材料、比賽報名或活動組織費用 |
| 實驗材料 | 耗材包、電子元件、工具配件、實驗小件等 |
| 食品與集體採購 | 活動期間統一訂購食品、飲品或其他公共用品 |
| 社團周邊 | 徽章、貼紙、記錄本、紀念品等 |
| 其他事項 | 以活動說明、系統公告或管理團隊確認的規則為準 |

## 功勳不能做什麼

!!! warning "使用邊界"
    | 不能 | 說明 |
    | --- | --- |
    | 會員之間自由轉讓 | 不支持 |
    | 私下買賣 | 不支持 |
    | 用於社團外交易 | 不支持 |
    | 隨時部分提現 | 不支持；退款原則上與賬戶註銷或退會綁定 |

    任何繞過系統、私下交易或利用漏洞獲取功勳的行為，都可能導致賬戶限制或社團處理。

## 會員的權利

| 權利 | 內容 |
| --- | --- |
| 知情權 | 查看本人賬戶餘額、入賬明細、使用明細、獎勵明細與退會處理記錄 |
| 查閱公開賬本 | 查看社團公開賬本及本人相關明細（敏感信息按規則脫敏或分級展示） |
| 申訴與覆核 | 對記錄、扣款、獎勵或退款有異議時，可提出申訴或申請覆核 |
