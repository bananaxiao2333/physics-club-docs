# 功勳系統

<p class="memorial-kicker">LATE STAGE · THE MERIT SYSTEM</p>

> 功勋系统是物理社后期尝试建立的一套内部会费、活动、贡献和奖励记录机制。
> 它最初源于对社费透明、活动核算和成员贡献记录的需求，后来逐步发展为包含
> 固定资金池、流动资金池、个人账户、公开账本和奖励池的电子系统。
>
> 在这个系统中，成员缴费、参加活动、领取物资、获得奖励和申请退款都会留下记录。
> **系统并不只是为了算账，更是为了让社团运转过程可被看见，让积极参与的人留下痕迹。**
>
> 虽然物理社已经解散，功勋系统仍然是这段历史中一项重要的组织实验。
> 它代表了物理社成员曾经对透明、公平、制度和长期运作的认真尝试。

## 為什麼會出現這套系統

功勳系統的出現，源於物理社在實際運作中面臨的幾個具體問題：

- 會費如何清楚記錄
- 活動費用如何核算
- 公共資金如何透明
- 積極參與者如何被看見
- 獎勵如何發放
- 成員如何查詢自己的餘額和歷史記錄

原始設想並非單純做一個電子表格，而是希望建立一套較完整的內部記錄系統：
會員繳納會費後，系統形成對應記錄；社團發生消費、活動、獎勵和結算時，
系統同步留下賬目；成員可以查看自己的賬戶與公開賬本。

核心訴求是三點：**透明 · 可追溯 · 可持續**。

## 基本定位

在最終公開表達中，功勳被定位為物理社內部的**會費與貢獻記錄工具**，
用於記錄會員繳納、活動使用、公共支出、獎勵發放和賬戶變動。

制度反覆強調的邊界：

!!! warning "功勳不是貨幣"
    功勳只在社團內部規則下使用，**不面向社團外部人員開放，不作為對外支付工具，
    不提供會員之間的自由轉讓、買賣、折現或其他外部流通功能**。

    這一邊界在多個白皮書版本中被保留下來，是整套設計的合規底線。

## 要解決的真實問題

| 環節 | 系統的作用 |
| --- | --- |
| 繳費 | 每筆入賬留下金額、時間、經辦人、審核狀態與憑證 |
| 活動 | 收入、成本、扣減與結餘形成項目記錄 |
| 物資 | 領取與結算可核對，差額有去向 |
| 獎勵 | 由獎池經多簽確認後發放，有明確原因與審核記錄 |
| 退款 | 與賬戶註銷或退會綁定，真實資金流出並核銷 |
| 查詢 | 會員可查看本人明細與社團公開賬本 |

## 它最終不只是一個軟件項目

> 从史料角度看，它体现了一个学生社团试图解决真实问题的过程：
> 会费不透明如何解决，活动成本如何核算，公共资金如何留存，
> 积极成员如何被奖励，系统如何避免失真，
> 会计部门如何从手工记账转向审计监督。

發布演講裡最具代表性的一句話是：

> 物理社不只是一个一起玩物理的地方，
> 也要成为一个**有规则、有账本、有贡献记录、有长期生命力**的社团。
