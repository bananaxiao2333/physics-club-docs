# 功勳系統

<p class="memorial-kicker">LATE STAGE · THE MERIT SYSTEM</p>

!!! info "資料出處"
    本頁據 [功勳系統史料整理](../../about/sources/index.md#merit-history "物理社功勋系统对话史料整理_纪念网站版.docx") 與
    [會員公開白皮書](../../about/sources/index.md#merit-whitepaper-member "物理社功勋系统会员公开白皮书_正式版第一版.docx") 整理。

    前者是**專門為這座紀念網站編寫的史料整理稿**（整理日期 2026 年 9 月 18 日），
    並明確給出了本站應採用的三層公開邊界。

> 功勳系統是物理社後期嘗試建立的一套內部會費、活動、貢獻和獎勵記錄機制。
> 它最初源於對社費透明、活動核算和成員貢獻記錄的需求，後來逐步發展為包含
> 固定資金池、流動資金池、個人賬戶、公開賬本和獎勵池的電子系統。
>
> 在這個系統中，成員繳費、參加活動、領取物資、獲得獎勵和申請退款都會留下記錄。
> **系統並不只是為了算賬，更是為了讓社團運轉過程可被看見，讓積極參與的人留下痕跡。**
>
> 雖然物理社已經解散，功勳系統仍然是這段歷史中一項重要的組織實驗。
> 它代表了物理社成員曾經對透明、公平、制度和長期運作的認真嘗試。

—— 該文件第 13 章「紀念網站可用短文」，按其授權原文引用

## 系統的由來

功勳系統的出現，源於物理社在實際運作中面臨的幾個具體問題：

- 會費如何清楚記錄
- 活動費用如何核算
- 公共資金如何透明
- 積極參與者如何被看見
- 獎勵如何發放
- 成員如何查詢自己的餘額和歷史記錄

原始設想並非單純做一個電子表格，而是希望建立一套較完整的內部記錄系統：
會員繳納會費後，系統形成對應記錄；社團發生消費、活動、獎勵和結算時，
系統同步留下賬目；成員可以查看自己的賬戶與公開賬本。

核心訴求是三點：**透明 · 可追溯 · 可持續**。

## 基本定位

在最終公開表達中，功勳被定位為物理社內部的**會費與貢獻記錄工具**，
用於記錄會員繳納、活動使用、公共支出、獎勵發放和賬戶變動。

制度反覆強調的邊界：

!!! warning "功勳不是貨幣"
    功勳只在社團內部規則下使用，**不面向社團外部人員開放，不作為對外支付工具，
    不提供會員之間的自由轉讓、買賣、折現或其他外部流通功能**。

    這一邊界在多個白皮書版本中被保留下來，是整套設計的合規底線。

## 要解決的真實問題

| 環節 | 系統的作用 |
| --- | --- |
| 繳費 | 每筆入賬留下金額、時間、經辦人、審核狀態與憑證 |
| 活動 | 收入、成本、扣減與結餘形成項目記錄 |
| 物資 | 領取與結算可核對，差額有去向 |
| 獎勵 | 由獎池經多簽確認後發放，有明確原因與審核記錄 |
| 退款 | 與賬戶註銷或退會綁定，真實資金流出並核銷 |
| 查詢 | 會員可查看本人明細與社團公開賬本 |

## 它最終不只是一個軟件項目

> 從史料角度看，它體現了一個學生社團試圖解決真實問題的過程：
> 會費不透明如何解決，活動成本如何核算，公共資金如何留存，
> 積極成員如何被獎勵，系統如何避免失真，
> 會計部門如何從手工記賬轉向審計監督。

發布演講裡最具代表性的一句話是：

> 物理社不只是一個一起玩物理的地方，
> 也要成為一個**有規則、有賬本、有貢獻記錄、有長期生命力**的社團。
