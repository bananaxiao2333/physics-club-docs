## 前言 · 為什麼需要功勳系統

物理社的日常運行離不開會費、活動經費、實驗材料、公共器材和成員貢獻。
過去如果只依賴人工記賬，容易出現**記錄分散、憑證不完整、成員難以核對、活動費用難以追蹤**等問題。
功勳系統的設立，是為了用**統一、透明、可追溯**的方式記錄社團資金與成員賬戶變化。

> 功勋系统的目标不是让会员承担复杂的财务工作，而是让每位会员清楚知道：
> 自己的账户如何增加，如何使用，参加活动时如何扣减，获得奖励时如何入账，
> 退会时如何处理，以及发生争议时如何查询和申诉。

**一句話說明**：功勳是物理社內部使用的**賬戶記錄單位**，
用於記錄會員繳費、活動費用、物資領取、獎勵發放、項目結算和退會處理等事項。

## 一 · 功勳系統的定位

### 1.1 系統性質

功勳系統是物理社內部的**會費與活動記錄系統**。系統圍繞總賬戶、資金池、
個人賬戶和公開賬本運行，用於提高社團資金使用的透明度和可核查性。

> 功勋只在物理社内部规则下使用，**不面向社团外部人员开放，不作为社团外部支付工具，
> 不提供会员之间的自由转让、买卖、折现或其他外部流通功能**。

### 1.2 會員需要理解的重點

| 事項 | 公開說明 |
| --- | --- |
| **賬戶記錄** | 每位會員擁有個人賬戶，用於查看本人功勳餘額、入賬、使用、獎勵和退會處理記錄 |
| **總賬戶** | 總賬戶記錄物理社整體資金變化，並區分固定資金池和流動資金池 |
| **公開賬本** | 會員可以查看社團公開賬本及本人相關明細，敏感信息按規則脫敏或分級展示 |
| **獎勵發放** | 獎勵由系統記錄並由管理員審核發放，**不承諾固定發放或固定回報** |
| **退款退會** | 退款原則上與賬戶註銷或退會處理相結合，**不設置隨時部分提取** |

## 二 · 基本概念

以下定義以**會員側使用**為主，不涉及後臺內部執行參數。

| 概念 | 會員側解釋 |
| --- | --- |
| **功勳** | 物理社內部使用的賬戶記錄單位，用於記錄繳費、消費、活動、獎勵、退款和項目結算 |
| **個人賬戶** | 每位會員名下的功勳記錄賬戶，展示本人餘額和本人相關流水 |
| **總賬戶** | 物理社整體資金與功勳變化的總記錄賬戶 |
| **固定資金池** | 總賬戶中的公共管理部分，用於支持社團公共事務、預墊費用、公共器材、活動基礎保障及其他經規則確認的事項 |
| **流動資金池** | 總賬戶中的日常使用部分，與會員活動、物資領取、項目結算和個人賬戶使用關係更直接 |
| **公開賬本** | 向會員展示的社團整體賬務與項目記錄，包括必要的收入、支出、結餘、憑證和說明 |
| **獎勵發放** | 社團根據活動表現、任務完成、項目貢獻或其他公開規則向會員賬戶發放的功勳記錄 |
| **項目結算** | 活動、材料包、外賣、食品、社團周邊或其他項目完成後，對收入、成本、扣減和結餘進行記錄 |

完整術語表見 [術語表](glossary.md)。

## 三 · 賬戶與資金池

### 3.1 總賬戶與個人賬戶

功勳系統以**總賬戶**為核心。總賬戶記錄物理社整體資金變化，
個人賬戶記錄每位會員自己的功勳變化。
**所有個人賬戶的變動最終都應能在總賬戶中找到對應記錄。**

每位會員可以查看：

- 本人賬戶餘額
- 本人入賬明細
- 本人使用明細
- 本人獎勵明細
- 本人退會處理記錄

管理賬戶負責登記、審核和維護系統總賬。

### 3.2 固定資金池與流動資金池

總賬戶下設置固定資金池和流動資金池。
固定資金池主要承擔社團公共事務和管理需要；
流動資金池主要承擔會員日常活動、物資領取和項目結算中的使用需求。

> 会员缴费或其他入账进入系统后，会根据**当期公示或活动说明**进入相应资金池和账户。
> 具体比例、适用范围和变动安排，以物理社正式公告、活动说明或系统记录为准。

### 3.3 簡化賬本關係

為方便會員理解，系統的簡化關係可以表示為：

```text
L = Σ Aᵢ
```

- `L` —— 流動資金池中與個人賬戶相關的合計餘額
- `Aᵢ` —— 第 i 位會員的個人賬戶餘額

當一筆金額為 `x` 的繳費或入賬進入系統，並按當期規則使用比例 `r` 計入固定資金池時：

```text
固定资金池增加 = x × r
个人账户增加   = x × (1 − r)
```

!!! note "比例不由個人臨時決定"
    具體比例應以**當期公告、繳費說明、活動說明或系統記錄**為準。
    **已完成的歷史記錄原則上不隨意回改。**

## 四 · 功勳的取得

### 4.1 繳費取得

會員繳納會費或按活動規則完成充值後，系統會根據實際入賬金額和當期規則記錄對應功勳。
繳費記錄應包含**金額、時間、經辦人、審核狀態和必要憑證**。

> 部分缴费可能按照当期规则分配至固定资金池，用于社团公共事务；
> 其余部分进入会员个人账户。**会员在缴费前应查看对应说明。**

### 4.2 獎勵取得

會員參與活動、完成任務、組織項目、維護器材、協助管理、提交成果或作出其他貢獻時，
可以根據活動規則獲得獎勵。**獎勵發放應有明確原因和審核記錄。**

### 4.3 更正取得

如系統記錄存在差錯，經核查後可以通過**更正記錄**修正賬戶。
更正記錄應說明原因，**不應直接刪除原始記錄**。

### 4.4 其他經公示確認的取得方式

社團可以根據活動安排或項目需要設置其他取得方式，
但應在**活動開始前或入賬前**進行說明，並在系統中保留記錄。

## 五 · 功勳的使用

### 5.1 可使用場景

| 場景 | 常見說明 |
| --- | --- |
| **活動費用** | 實驗活動、講座材料、比賽報名或活動組織費用 |
| **實驗材料** | 耗材包、電子元件、工具配件、實驗小件等 |
| **食品與集體採購** | 活動期間統一訂購食品、飲品或其他公共用品 |
| **社團周邊** | 徽章、貼紙、記錄本、紀念品等 |
| **其他事項** | 以活動說明、系統公告或管理團隊確認的規則為準 |

### 5.2 使用流程

1. 會員查看活動或項目說明，確認所需功勳、活動內容和結算方式；
2. 會員報名、下單或確認參與後，系統生成**待處理記錄**；
3. 活動完成或物資領取後，系統形成**正式使用記錄**；
4. 如存在多收、少收、取消活動或記錄錯誤，由管理員通過**更正記錄**處理。

### 5.3 使用限制

!!! warning "會員必須知道的邊界"
    功勳**不支持**會員之間自由轉讓，**不支持**私下買賣，
    **不支持**用於社團外交易，**不支持**隨時部分提現。

    任何繞過系統、私下交易或利用漏洞獲取功勳的行為，
    都可能導致**賬戶限制或社團處理**。

## 六 · 活動、物資與項目結算

活動、物資和集體採購是功勳系統最常見的使用場景。
為了讓會員清楚了解扣減依據，**每個項目原則上應形成項目記錄**。

| 項目類型 | 結算要點 |
| --- | --- |
| 活動項目 | 按報名人數與預算形成收入，活動結束後核銷實際成本，結餘進入固定資金池 |
| 物資領取 | 個人賬戶支付，外部成本核銷，差額進入固定資金池 |
| 食品與集體採購 | 按實際訂購與分攤記錄 |
| 社團周邊 | 按製作成本與領取數量記錄 |

結算完成後，會員可在個人賬戶中看到屬於本人的扣減明細，
社團整體項目記錄在公開賬本中體現。

## 七 · 獎勵發放

獎勵機制的目標，是讓**積極參加任務、組織活動、承擔社團工作和貢獻較多的會員被看見**。

制度**不採用隨意發放**，而是通過活動規則、獎池設置和多簽確認來控制：

1. **上限**：非戰時情況下，獎勵池上限暫時限制為**小於對應活動盈利金額**；
2. **自定義**：獎池金額按**每次活動**自定義；
3. **多簽**：每次開放獎池後，需要 **3 名以上管理員完成 grant 多簽**，才可發放。

獎勵發放完成後，系統記錄**獎池減少**與**個人賬戶增加**。
對普通會員而言，其表現形式是賬戶收到一筆獎勵；
對管理層而言，其本質是固定資金池中已鎖定的獎勵額度向個人賬戶轉移。

!!! note "獎勵不構成回報承諾"
    白皮書在「會員需要理解的重點」中明確：
    獎勵「**不承諾固定發放或固定回報**」。
    這與 [04.27 集會第 9 頁](../../collection/gatherings/0427.md) 的積分定位一致。

## 八 · 公開賬本與信息查看

公開賬本是功勳系統的核心價值之一。
早期材料中明確提到：**秘密記賬容易導致信任危機**。
因此系統需要讓會員可以查看整體資金操作記錄和自己賬戶的相關記錄。

公開賬本的目標**不是公開所有個人隱私**，而是公開與社團公共事務有關的必要信息：

- 資金池大小
- 公共支出用途
- 活動結算
- 獎勵池發放
- 重大賬目調整

### 權限

| 角色 | 權限 |
| --- | --- |
| 普通會員 | 以**只讀**為主 |
| 管理員 | 錄入、審核和發起操作 |
| 重要事項 | 需要**多名管理員確認** |

若成員對記錄、扣款、獎勵或退款有異議，可以提出**申訴或申請覆核**。

## 九 · 退款、退會與賬戶註銷

!!! warning "退款與退會綁定"
    退款**原則上與賬戶註銷或退會處理相結合**，**不設置隨時部分提取**。

    會員如需退款，須經申請與審核流程；
    真實資金流出後，對應記錄被**核銷**，賬戶關閉或凍結。

## 十 · 成員權利

| 權利 | 內容 |
| --- | --- |
| **知情權** | 了解與本人權益相關的事務，包括賬戶餘額、入賬、使用、獎勵與退會處理記錄 |
| **查閱公開賬本** | 查看社團公開賬本及本人相關明細（敏感信息按規則脫敏或分級展示） |
| **申訴權** | 對記錄、扣款、獎勵或退款有異議時，可提出異議、補充說明或申請覆核 |
| **要求公示依據** | 必要時可要求公示處理所依據的規則 |

## 十一 · 成員義務與使用限制

- 按社團規則使用功勳，**不進行任何形式的外部流通**；
- 不繞過系統進行私下交易；
- 不利用漏洞獲取功勳；
- 繳費前查看對應說明；
- 發現記錄差錯時通過**更正流程**處理，而非自行主張。

違反上述義務可能導致賬戶限制或社團處理。

## 十二 · 常見問題

??? question "功勳可以轉讓給別人嗎？"
    不可以。功勳**不支持會員之間自由轉讓，也不支持私下買賣**。

??? question "功勳可以換成現金嗎？"
    不可以。功勳**不支持折現，也不支持隨時部分提現**。
    退款原則上與**賬戶註銷或退會**綁定。

??? question "獎勵是固定的嗎？"
    不是。獎勵按活動規則與獎池設置發放，
    **不承諾固定發放或固定回報**。

??? question "我怎麼知道錢花到哪裡了？"
    通過**公開賬本**。會員可以查看資金池大小、公共支出用途、
    活動結算、獎勵池發放和重大賬目調整，以及本人相關明細。

??? question "記錄錯了怎麼辦？"
    通過**更正記錄**處理。更正記錄應說明原因，
    **不應直接刪除原始記錄**。

??? question "我對處理結果不滿意怎麼辦？"
    可以提出**異議、補充說明或申請覆核**。
    制度明確要求避免「最終解釋權歸社團所有」這類單向條款。

## 附錄 · 會員操作流程

1. **繳費** → 查看當期說明 → 系統按比例分配 → 個人賬戶入賬
2. **查看** → 登錄個人賬戶 → 查看餘額與流水
3. **參與** → 查看活動說明 → 報名或下單 → 生成待處理記錄 → 完成後轉正式記錄
4. **領取物資** → 個人賬戶支付 → 外部成本核銷
5. **獲得獎勵** → 獎池經多簽開放 → 個人賬戶增加
6. **核對與申訴** → 查閱公開賬本 → 有異議時申請覆核
