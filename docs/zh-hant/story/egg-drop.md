# 雞蛋撞地球

<p class="memorial-kicker">THE FIRST EXPERIMENT</p>

!!! note "關於這一頁的依據"
    `资料/物理社招新宣讲稿.wps` 將「雞蛋撞地球」列為物理社過去一年的活動之一，
    並寫明它的意義是「考驗動手能力，更體現工程思維與物理建模能力」。

    但留存材料中**沒有該活動的獨立方案、日期、規則或成績記錄**，
    提到它的只有這一份宣講稿。因此本頁不給日期、不寫賽果，
    下文的物理問題描述是對這類挑戰的**通用說明**，不是活動當天原話。

## 我們做的第一件事

讓一枚雞蛋從高處落下來，然後完好無損。

聽起來像玩笑，但這是一個完整的工程問題：把衝擊力在時間與空間上攤開，
用結構變形換取峰值應力下降，用緩衝層延續動量傳遞的時間。
脆弱的不是雞蛋，缺少設計的結構才是。

## 這類挑戰真正在問的問題

- 落地瞬間的衝量如何被結構吸收，而不是被蛋殼吸收
- 緩衝材料的厚度、剛度與排布方式對峰值應力的影響
- 重心位置對落地姿態的影響：姿態一歪，前面算的都白算

## 宣講稿裡的說法

> 同学们通过结构设计与缓冲优化，让看似脆弱的鸡蛋在高空落地中成功「生存」，
> 这一过程不仅考验动手能力，更体现了工程思维与物理建模能力。

—— `资料/物理社招新宣讲稿.wps`

## 它為什麼被反覆講起

這場活動後來成為物理社在招新宣講裡**第一個被講起的故事**——
因為它最直觀地回答了「這個社團到底做什麼」：

**物理不是紙面上的公式，它發生在手裡、眼前，以及一次失敗之後重新搭起來的那五分鐘。**
