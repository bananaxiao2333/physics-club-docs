## 這會是一場什麼活動

這不是一次「摺紙活動」。它把物理、工程、競賽與創意放進同一塊場地：
**報名、試飛、激光測距、實時投屏、頒獎、破紀錄**，全部由一個學生社團自己跑完。

集會宣傳稿裡的說法是：

> 你可以是参赛者，也可以是设计者，甚至只是一个观察者——
> 但无论哪种身份，你都会看到：一张普通的 A4 纸，
> 是如何在结构、空气动力学与技巧的共同作用下，飞出极限距离。

## 正式比賽怎麼跑

**版本 A** —— 出處：`资料/A4纸飞行节活动执行流程(1).docx`

- **小組賽**：1 次預飛 + **3 次**正式飛行，取最佳成績選出 **8 強**
- **8 強決賽**：**5 次**飛行，疊加小組賽成績取最佳，決出冠亞季軍與**校園紀錄保持者**
- **師生挑戰賽**：學生組別自主對接教師競賽，教師可使用物理社器材，**勝敗均發獎**

**版本 B** —— 出處：`资料/飞行节分工安排 2.docx`

- **小組賽**：1 次預飛 + **2 次**正式飛行，取最佳成績選出 8 強
- **8 強決賽**：**3 次**飛行，疊加小組賽成績取最佳

兩版在飛行次數上不一致，此處不合併。

## 報名

| 口徑 | 出處 |
| --- | --- |
| 以小組報名，每組 **2–6 人**，現場開放報名通道 | `物理社飞行节集会宣传稿.wps` |
| 每組 **4–6 人** | `紙飛機挑戰賽 签到表.docx` |
| 分組**最多六人**，按組頒獎 | `A4纸飞行节活动执行流程(1).docx` |

成績口徑是一致的：**以起點和紙飛機落點之間的直線距離為最終成績**
（`物理社集会0427.pptx` 第 2 頁「測量須知」）。

## 現場是怎麼保證「算得清」的

這是整場活動裡技術含量最高的部分：

| 崗位 | 職責 |
| --- | --- |
| 總裁判長（sink） | 規則解讀、判定飛行是否有效、最終裁定賽事爭議 |
| 檢錄 | 選手檢錄與秩序維護，禁止無關人員進入飛行區 |
| 測距 | 激光測距儀（500 m 量程）精準記錄飛行數據 |
| 計分 | 實時投屏公示，確保公開透明 |
| 記錄 | 成績登記在白板上，賽後形成公示名單與紀錄展板 |

選擇激光測距而不是皮尺，是因為「直線距離」這條規則要求可復現、可爭議時可覆核的測量方式。

## 那天留下的東西

一場活動的價值不只在當天。收尾期計劃裡還有：

- **24 小時內**完成活動回顧推文與短視頻的發布，素材按類別歸檔，提交傳播數據復盤報告
- **3 天內**公示最終獲獎名單與校園紀錄，製作並擺放校園紀錄展板
- 完成剩餘物料盤點入庫、經費核對與報銷材料提交
