# 留存的原檔

<p class="memorial-kicker">THE MEMORY COLLECTION · SURVIVING ORIGINALS</p>

## 留存原始件的三個類別

講稿、設計稿與照片。它們不是為紀念館準備的，是當時做事時留下的，
所以保住了**當時的樣子**——包括還沒落地的設想、還沒用完的模板、
以及拍攝日期只寫得清月份的那些照片。

這一部分收攏三類原件：

| 分區 | 內容 | 規模 |
| --- | --- | --- |
| [影像檔案](archive/index.md) | 來自留存資料的照片 | 十幀 |
| [設計原檔](design/index.md) | 社徽、社牌、導引牌、海報、杯身設計 | 一套參數化工程 |
| [集會原稿](gatherings/index.md) | 2026 年春季三次集會的演示文稿 | 31 頁，保留原有順序 |

## 歸入同一部分的理由

三類的共同點是：**它們都是原件**，不是轉述。

因此記述上採用同一套口徑：

- **逐頁保留原貌**，包括其中尚未落地的內容；
- 材料之間口徑不一致時**並列保留各版本**，不推定哪一版最終執行；
- 過期目錄中的草案**僅作草案**存檔，不推定為實際發放版本。

每頁正文開頭都註明各自的 `资料/` 原始件，可以逐項核對。
