!!! note "A few notes on this list"
    - In the “venue” column, the whiteboard is marked “main sports field **& later use**”,
      which indicates that the item was planned as a reusable asset rather than a one-off material;
    - The “product link” column contains both Taobao links and Xianyu mini-program links,
      which indicates that the purchasing channels were not uniform;
    - **The total of ¥372.6 was added up by this site from the subtotals in the list**; the original list has no total row.

### Two key pieces of equipment

**Laser rangefinder (500 m, ¥159)** — the highest unit price in the list, and the only one with a single purpose.
Its presence corresponds directly to the scoring basis established at the [04.27 assembly](../gatherings/0427.md):

> taking the **straight-line distance between the start point and where the paper plane lands** as the final result

A straight-line distance calls for a measurement that can be reproduced and re-checked when disputed; that is why laser ranging was used rather than a tape measure.

**Custom signature board (2.3 m × 3.5 m, ¥158)** — an area of about **8.05 m²**,
the only item on the list that had to be custom-made, and second only to the rangefinder in unit price.

## On-site forms

The competition prepared **3** blank forms. All are in Traditional Chinese, and **none of them has any entries**.

=== "Registration sheet"

    > **紙飛機挑戰賽 報名表**

    | Field (as printed) | Notes |
    | --- | --- |
    | `組名` | Name of the entering group |
    | `組成員` | With the example “e.g. 10S胡益成” |

    !!! note "The class code in the example"
        The `10S` in the example “**10S**胡益成” is a class code,
        consistent with the coding system used in the [05.12 grouping table](../gatherings/0512.md)
        (10S / 10V / 10G / 10Z / 10J / 10A / 10H / 10K / 9V / 9Z / 7V).

=== "Results sheet"

    > **紙飛機挑戰賽 成績表**

    | Field (as printed) | Notes |
    | --- | --- |
    | `時間` | The time recorded |
    | `選手編號` | Competitor number |
    | `比賽成績（距離/米）` | The result, in **metres** |
    | `測量員` | Signature of the distance measurer |
    | `記錄員` | Signature of the recorder |

    !!! note "Two signatures"
        Every result requires **the measurer and the recorder to sign separately**,
        which corresponds to the posts in the run of show: “3 people handle laser ranging”, “2 people score and post the results live by projection”.

    The form is a **two-part repeated layout**, so that two groups can be recorded side by side.

=== "Sign-in sheet"

    > **紙飛機挑戰賽 簽到表**

    | Field (as printed) | Notes |
    | --- | --- |
    | `時間` | The time of arrival |
    | `組名` | Group name |
    | `人數` | **4–6 people** (this limit is printed directly on the form) |
    | `參與者（備註班級）` | Participant name, with the class noted |
    | `編號（工作人員填寫）` | The number, filled in by staff |

    !!! warning "“4–6 people” conflicts with other material"
        The sign-in sheet prints “**4-6人**” in its header;
        the assembly publicity draft says “registration by group, **2-6 people**”;
        the run of show document says “groups of **at most six**”.

        All three versions are kept side by side; this site does not merge them.

### What the three forms have in common

| Feature | Notes |
| --- | --- |
| All blank | No actual entries of any kind |
| All in Traditional Chinese | Consistent with the assembly presentation |
| All have a “時間” (time) column | Showing that the design required **every entry to record a time** |
| None has names | Only fields, with no names pre-filled |

!!! quote "One thing this confirms"
    **The final results of the flight festival are not recorded in the surviving material.**

    All three forms are blank templates, so this site publishes no placings,
    distance results or “school record” figure.
