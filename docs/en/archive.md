## Every surviving photograph has a timestamp

The source folder `微信assets/` holds **19 image files**. WeChat filenames
preserve a timestamp, so each of them is datable.

!!! warning "What these times mean"
    A WeChat filename timestamp records **when the file was processed or saved
    by WeChat**. It is usually close to the moment of capture, but it is
    **not the shutter time**.

    This site uses them to establish the rough period in which activity
    happened, not to assert exact capture times.

### On mapping page images to source files

The images on this site are **re-encoded** from the originals, optimised for
web viewing.

!!! note "Why source filenames are not given per photograph"
    Several surviving files have **identical dimensions** — for example
    `20260421123547`, `20260421123548` and `20260421130606` are all 1280 × 853 —
    so after re-encoding there is no way to establish a unique correspondence
    from file properties alone.

    This site therefore **does not label each page photograph with a source
    filename**. Giving a confident answer on insufficient evidence is worse
    than giving none.
