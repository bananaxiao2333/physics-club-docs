## Document lineage

The merit system grew from scattered ideas into a complete set of documents. As recorded in chapter 9 of `资料/物理社功勋系统对话史料整理_纪念网站版.docx`:

| Document | Audience | Content |
| --- | --- | --- |
| *Physics Club Merit System Fund-Flow White Paper*, v1.0 | Draft for officers | The first systematic arrangement of the rules on fund pools, accounts, crediting, spending, project balances, the reward pool and the handling of withdrawal from the club |
| *Physics Club Merit System Fund-Flow White Paper*, Formal Edition, First Version | Formal draft for officers | Adds more precise formulas, a cap on the reward pool and the administrators' multi-signature grant rule |
| *Physics Club Merit System Member Public White Paper*, Formal Edition, First Version | All members | Explains what merit is, how it is used, how rewards are given and how the ledger is published |
| Release speech script | All members | Set out the value of the merit system and its basic rules when the system was formally released |
| *Physics Club Merit System Dialogue Historical Compilation*, Memorial-Site Edition | The memorial site | A distillation of the dialogue material, including a timeline, a glossary and retention recommendations |

The material also records: **after the white papers took shape, the Physics Club had already built an electronic system to match the rules.**

## The transformation of the accounting side

Once the system went live, a question arose: since the system can record things automatically, is there still any need for the accounting side to exist?

The conclusion reached in the dialogue was that the accounting side is **not only still useful, but has a more important role**.
A system replaces repetitive bookkeeping, but it cannot replace confirming authenticity, reviewing vouchers, reconciling funds,
re-checking the reward pool, reviewing refunds and producing monthly reports.

The accounting side was therefore advised to upgrade into a “**Finance and Audit Department**” or a “Finance Oversight Department”:

> The system keeps the record; the accounting side makes that record trustworthy.

Its core duties include: reconciling real funds against system records, reviewing vouchers, re-checking activity settlement,
confirming that the reward pool does not exceed the limits set by the rules, taking part in multi-signature, handling refunds and closures,
publishing monthly financial reports and monitoring abnormal flows.

    Appendix C of `资料/物理社功勋系统对话史料整理_纪念网站版.docx` sets out explicitly a **three-tier retention recommendation**,
    and this site **follows it strictly**:

    | Tier | What that file requires | What this site does |
    | --- | --- | --- |
    | **Public web pages** | Host the short usable text, the timeline and a short glossary | Done: [The Merit System](index.md), [The Ledger Model](ledger.md), [Glossary](glossary.md) |
    | **Downloadable document** | Provide **this historical compilation document** as a complete public edition, retained | Provided: see the download below |
    | **Internal archive** | Keep the original documents, white papers, screenshots and descriptions of the electronic system, **but do not publish directly any content containing privacy, back-office parameters or contentious wording** | **Not published**: original files containing back-office operating parameters or internally contentious wording are not published on this site |

    That file puts it this way: “This keeps the history while sparing the memorial site unnecessary misunderstanding and controversy.”

## Historical value

> In the end the merit system was more than a software project.
> It was an **institutional experiment** by the Physics Club in organisational governance, financial transparency and member incentives.
>
> Even though the Physics Club has disbanded, the value the merit system left behind still lies in this:
> it records a group of members who once thought seriously about how to make a club run **more clearly, more fairly and more professionally**.
