!!! note "How the group roster was produced"
    The original table uses **merged cells**, and flattening it would lose which column a name belongs to.
    The roster on this page was entered cell by cell, by parsing the table XML of the deck and following cell coordinates,
    rather than transcribed linearly in reading order.

    The group colours (`#910000` / `#3b229f` / `#887300` / `#6b0089`)
    are in [Member group roster](../../about/sources/index.md#badge-roster-members).
