# Design Archive

<p class="memorial-kicker">THE MEMORY COLLECTION · DESIGN ARCHIVE</p>

!!! info "The badge was a design project, not a set of images"
    The original sources live in `物理社工牌/` and document a **reproducible
    workflow**:

    - `README.txt` — edit `物理社工牌设计全部模板.svgz` in Inkscape, batch-export
      all pages, then run NextGenerator over the filling roster to generate each
      badge, writing output to `dist`
    - `source/物理社工牌设计全部模板.svgz` — the master template
    - `source/物理社成员组填充名单.csv` — group names, codes `S/N/P/M`, colour values
    - `source/物理社管理层填充名单.csv` — the 14 officers, positions, English names
    - `source/*.svg` — front and back vector templates for member and officer badges
    - `material/*.ttc` — fonts (Microsoft YaHei family, plus BMDOHYEON)

    Strip this away and the badge is just a picture. Keep it, and the badge is
    reproducible.

## Let the originals speak

Those blues, those characters, those carefully arranged details.
From badge to wayfinding signs, the originals are preserved as they were.

## Every orbit pointed to the same place

The blue club emblem comes from a surviving original. Around it the club built
an entire visual language: badges, group markers, wayfinding signs, and posters —
colour and type all growing from the same mark.
