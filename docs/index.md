## 物理之外，是自由探索的我们

ASJ 英东物理社曾希望创造一个平台：**让学生用自己的方式理解物理、表达物理、实践物理。**

这里收藏了它留下的讲稿、活动方案、设计与影像。社团已经不复存在，但那些认真做过的事，值得被记住。
