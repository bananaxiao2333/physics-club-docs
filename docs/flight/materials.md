### 两件关键器材

!!! info inline end "测距仪规格"

    500 m 量程 · ¥159 · 采购 1 件

**激光测距仪（500 m，¥159）** —— 全场单价最高、用途唯一的一件。
它的存在直接对应 [04.27 集会](../collection/gatherings/0427.md) 确立的成绩口径：

> 以**起点和纸飞机落点之间的直线距离**为最终成绩

直线距离要求可复现、可争议时复核的测量方式，这是采用激光测距而非皮尺的原因。

**定制签名版（2.3 m × 3.5 m，¥158）** —— 面积约 **8.05 m^2^**，
是清单中唯一需要定制生产的物料，单价仅次于测距仪。

## 现场表单

赛事准备了 **3 份**空白表单，均为繁体中文，**没有任何填写记录**。

=== "报名表"

    > **纸飞机挑战赛 报名表**

    | 栏目 | 说明 |
    | --- | --- |
    | 组名 | 参赛小组名称 |
    | 组成员 | 附示例「例如：10S胡益成」 |

    !!! note "示例中的班级编码"
        示例「**10S**胡益成」中的 `10S` 是班级编码，
        与 [05.12 分组表](../collection/gatherings/0512.md) 中使用的编码体系一致
        （10S / 10V / 10G / 10Z / 10J / 10A / 10H / 10K / 9V / 9Z / 7V）。

=== "成绩表"

    > **纸飞机挑战赛 成绩表**

    | 栏目 | 说明 |
    | --- | --- |
    | 时间 | 记录时刻 |
    | 选手编号 | 选手编号 |
    | 比赛成绩（距离/米） | 成绩，单位为**米** |
    | 测量员 | 测距员签名 |
    | 记录员 | 记录员签名 |

    !!! note "双人签核"
        每一条成绩都要求 **测量员与记录员分别签名**，
        这与执行流程中「3 人负责激光测距」「2 人计分并实时投屏公示」
        的岗位设置相对应。

    表单为**两联重复版式**，可并排记录两组。

=== "签到表"

    > **纸飞机挑战赛 签到表**

    | 栏目 | 说明 |
    | --- | --- |
    | 时间 | 到场时刻 |
    | 组名 | 小组名称 |
    | 人数 | **4–6 人**（表格内直接印有此限值） |
    | 参与者（备注班级） | 参与者姓名，备注班级 |
    | 编号（工作人员填写） | 工作人员填写编号 |

    !!! warning "「4–6 人」与其他材料冲突"
        签到表的表头印有「==4-6人==」；
        而集会宣传稿写「以小组报名 人数 ==2-6 人==」；
        执行流程文档写「分组==最多六人==」。

        三个版本并列保留，本站不合并。

### 三份表单的共同点

| 特征 | 说明 |
| --- | --- |
| 全部空白 | 无任何实际填写记录 |
| 全部繁体 | 与集会演示文稿一致 |
| 均有「时间」列 | 说明设计上要求**逐条记录时刻** |
| 均无人名 | 只有栏目，没有预设名单 |

!!! quote "由此可以确认的一件事"
    **飞行节的最终赛果在留存材料中没有记录。**

    三份表单全部为空白模板，本站因此不公布任何名次、
    距离成绩或「校园纪录」数值。
