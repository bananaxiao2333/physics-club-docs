会员侧规则全文¶

MEMBER-FACING RULES

资料出处与公开范围

本页据 会员公开白皮书 整理。 该文件标注「适用对象：物理社全体会员」「内部公开传阅｜不得用于社团外商业宣传」。

该白皮书自身声明：涉及系统安全、后台审批、供应商谈判、未公开合作事项、 个人隐私及管理团队内部执行参数的内容不在公开版中展开。 因此本页内容已是由原始件划定的会员侧范围。

制度沿革见 功勋系统，管理层模型见 资金流转模型。

前言 · 为什么需要功勋系统¶

物理社的日常运行离不开会费、活动经费、实验材料、公共器材和成员贡献。 过去如果只依赖人工记账，容易出现记录分散、凭证不完整、成员难以核对、活动费用难以追踪等问题。 功勋系统的设立，是为了用统一、透明、可追溯的方式记录社团资金与成员账户变化。

功勋系统的目标不是让会员承担复杂的财务工作，而是让每位会员清楚知道： 自己的账户如何增加，如何使用，参加活动时如何扣减，获得奖励时如何入账， 退会时如何处理，以及发生争议时如何查询和申诉。

一句话说明：功勋是物理社内部使用的账户记录单位， 用于记录会员缴费、活动费用、物资领取、奖励发放、项目结算和退会处理等事项。

一 · 功勋系统的定位¶

1.1 系统性质¶

功勋系统是物理社内部的会费与活动记录系统。系统围绕总账户、资金池、 个人账户和公开账本运行，用于提高社团资金使用的透明度和可核查性。

功勋只在物理社内部规则下使用，不面向社团外部人员开放，不作为社团外部支付工具， 不提供会员之间的自由转让、买卖、折现或其他外部流通功能。

1.2 会员需要理解的重点¶

事项 公开说明
账户记录 每位会员拥有个人账户，用于查看本人功勋余额、入账、使用、奖励和退会处理记录
总账户 总账户记录物理社整体资金变化，并区分固定资金池和流动资金池
公开账本 会员可以查看社团公开账本及本人相关明细，敏感信息按规则脱敏或分级展示
奖励发放 奖励由系统记录并由管理员审核发放，不承诺固定发放或固定回报
退款退会 退款原则上与账户注销或退会处理相结合，不设置随时部分提取

二 · 基本概念¶

以下定义以会员侧使用为主，不涉及后台内部执行参数。

概念 会员侧解释
功勋 物理社内部使用的账户记录单位，用于记录缴费、消费、活动、奖励、退款和项目结算
个人账户 每位会员名下的功勋记录账户，展示本人余额和本人相关流水
总账户 物理社整体资金与功勋变化的总记录账户
固定资金池 总账户中的公共管理部分，用于支持社团公共事务、预垫费用、公共器材、活动基础保障及其他经规则确认的事项
流动资金池 总账户中的日常使用部分，与会员活动、物资领取、项目结算和个人账户使用关系更直接
公开账本 向会员展示的社团整体账务与项目记录，包括必要的收入、支出、结余、凭证和说明
奖励发放 社团根据活动表现、任务完成、项目贡献或其他公开规则向会员账户发放的功勋记录
项目结算 活动、材料包、外卖、食品、社团周边或其他项目完成后，对收入、成本、扣减和结余进行记录

完整术语表见 术语表。

三 · 账户与资金池¶

3.1 总账户与个人账户¶

功勋系统以总账户为核心。总账户记录物理社整体资金变化， 个人账户记录每位会员自己的功勋变化。 所有个人账户的变动最终都应能在总账户中找到对应记录。

每位会员可以查看：

  • 本人账户余额
  • 本人入账明细
  • 本人使用明细
  • 本人奖励明细
  • 本人退会处理记录

管理账户负责登记、审核和维护系统总账。

3.2 固定资金池与流动资金池¶

总账户下设置固定资金池和流动资金池。 固定资金池主要承担社团公共事务和管理需要； 流动资金池主要承担会员日常活动、物资领取和项目结算中的使用需求。

会员缴费或其他入账进入系统后，会根据当期公示或活动说明进入相应资金池和账户。 具体比例、适用范围和变动安排，以物理社正式公告、活动说明或系统记录为准。

3.3 简化账本关系¶

为方便会员理解，系统的简化关系可以表示为：

简化账本关系
L = Σ Aᵢ
  • L —— 流动资金池中与个人账户相关的合计余额
  • Ai —— 第 i 位会员的个人账户余额

当一笔金额为 x 的缴费或入账进入系统，并按当期规则使用比例 r 计入固定资金池时：

固定资金池的计入
固定资金池增加 = x × r
个人账户增加   = x × (1 − r)

比例不由个人临时决定

具体比例应以当期公告、缴费说明、活动说明或系统记录为准。 已完成的历史记录原则上不随意回改。

四 · 功勋的取得¶

4.1 缴费取得¶

会员缴纳会费或按活动规则完成充值后，系统会根据实际入账金额和当期规则记录对应功勋。 缴费记录应包含金额、时间、经办人、审核状态和必要凭证。

部分缴费可能按照当期规则分配至固定资金池，用于社团公共事务； 其余部分进入会员个人账户。会员在缴费前应查看对应说明。

4.2 奖励取得¶

会员参与活动、完成任务、组织项目、维护器材、协助管理、提交成果或作出其他贡献时， 可以根据活动规则获得奖励。奖励发放应有明确原因和审核记录。

4.3 更正取得¶

如系统记录存在差错，经核查后可以通过更正记录修正账户。 更正记录应说明原因，不应直接删除原始记录。

4.4 其他经公示确认的取得方式¶

社团可以根据活动安排或项目需要设置其他取得方式， 但应在活动开始前或入账前进行说明，并在系统中保留记录。

五 · 功勋的使用¶

5.1 可使用场景¶

场景 常见说明
活动费用 实验活动、讲座材料、比赛报名或活动组织费用
实验材料 耗材包、电子元件、工具配件、实验小件等
食品与集体采购 活动期间统一订购食品、饮品或其他公共用品
社团周边 徽章、贴纸、记录本、纪念品等
其他事项 以活动说明、系统公告或管理团队确认的规则为准

5.2 使用流程¶

  1. 会员查看活动或项目说明，确认所需功勋、活动内容和结算方式；
  2. 会员报名、下单或确认参与后，系统生成待处理记录；
  3. 活动完成或物资领取后，系统形成正式使用记录；
  4. 如存在多收、少收、取消活动或记录错误，由管理员通过更正记录处理。

5.3 使用限制¶

会员必须知道的边界

功勋不支持会员之间自由转让，不支持私下买卖， 不支持用于社团外交易，不支持随时部分提现。

任何绕过系统、私下交易或利用漏洞获取功勋的行为， 都可能导致账户限制或社团处理。

六 · 活动、物资与项目结算¶

活动、物资和集体采购是功勋系统最常见的使用场景。 为了让会员清楚了解扣减依据，每个项目原则上应形成项目记录。

项目类型 结算要点
活动项目 按报名人数与预算形成收入，活动结束后核销实际成本，结余进入固定资金池
物资领取 个人账户支付，外部成本核销，差额进入固定资金池
食品与集体采购 按实际订购与分摊记录
社团周边 按制作成本与领取数量记录

结算完成后，会员可在个人账户中看到属于本人的扣减明细， 社团整体项目记录在公开账本中体现。

七 · 奖励发放¶

奖励机制的目标，是让积极参加任务、组织活动、承担社团工作和贡献较多的会员被看见。

制度不采用随意发放，而是通过活动规则、奖池设置和多签确认来控制：

  1. 上限：非战时情况下，奖励池上限暂时限制为小于对应活动盈利金额；
  2. 自定义：奖池金额按每次活动自定义；
  3. 多签：每次开放奖池后，需要 3 名以上管理员完成 grant 多签，才可发放。

奖励发放完成后，系统记录奖池减少与个人账户增加。 对普通会员而言，其表现形式是账户收到一笔奖励； 对管理层而言，其本质是固定资金池中已锁定的奖励额度向个人账户转移。

奖励不构成回报承诺

白皮书在「会员需要理解的重点」中明确： 奖励「不承诺固定发放或固定回报」。 这与 04.27 集会第 9 页 的积分定位一致。

八 · 公开账本与信息查看¶

公开账本是功勋系统的核心价值之一。 早期材料中明确提到：秘密记账容易导致信任危机。 因此系统需要让会员可以查看整体资金操作记录和自己账户的相关记录。

公开账本的目标不是公开所有个人隐私，而是公开与社团公共事务有关的必要信息：

  • 资金池大小
  • 公共支出用途
  • 活动结算
  • 奖励池发放
  • 重大账目调整

权限¶

角色 权限
普通会员 以只读为主
管理员 录入、审核和发起操作
重要事项 需要多名管理员确认

若成员对记录、扣款、奖励或退款有异议，可以提出申诉或申请复核。

九 · 退款、退会与账户注销¶

退款与退会绑定

退款原则上与账户注销或退会处理相结合，不设置随时部分提取。

会员如需退款，须经申请与审核流程； 真实资金流出后，对应记录被核销，账户关闭或冻结。

十 · 成员权利¶

权利 内容
知情权 了解与本人权益相关的事务，包括账户余额、入账、使用、奖励与退会处理记录
查阅公开账本 查看社团公开账本及本人相关明细（敏感信息按规则脱敏或分级展示）
申诉权 对记录、扣款、奖励或退款有异议时，可提出异议、补充说明或申请复核
要求公示依据 必要时可要求公示处理所依据的规则

十一 · 成员义务与使用限制¶

  • 按社团规则使用功勋，不进行任何形式的外部流通；
  • 不绕过系统进行私下交易；
  • 不利用漏洞获取功勋；
  • 缴费前查看对应说明；
  • 发现记录差错时通过更正流程处理，而非自行主张。

违反上述义务可能导致账户限制或社团处理。

十二 · 常见问题¶

功勋可以转让给别人吗？

不可以。功勋不支持会员之间自由转让，也不支持私下买卖。

功勋可以换成现金吗？

不可以。功勋不支持折现，也不支持随时部分提现。 退款原则上与账户注销或退会绑定。

奖励是固定的吗？

不是。奖励按活动规则与奖池设置发放， 不承诺固定发放或固定回报。

我怎么知道钱花到哪里了？

通过公开账本。会员可以查看资金池大小、公共支出用途、 活动结算、奖励池发放和重大账目调整，以及本人相关明细。

记录错了怎么办？

通过更正记录处理。更正记录应说明原因， 不应直接删除原始记录。

我对处理结果不满意怎么办？

可以提出异议、补充说明或申请复核。 制度明确要求避免「最终解释权归社团所有」这类单向条款。

附录 · 会员操作流程¶

  1. 缴费 → 查看当期说明 → 系统按比例分配 → 个人账户入账
  2. 查看 → 登录个人账户 → 查看余额与流水
  3. 参与 → 查看活动说明 → 报名或下单 → 生成待处理记录 → 完成后转正式记录
  4. 领取物资 → 个人账户支付 → 外部成本核销
  5. 获得奖励 → 奖池经多签开放 → 个人账户增加
  6. 核对与申诉 → 查阅公开账本 → 有异议时申请复核
