04 / THE MEMORY COLLECTION · THE PHOTO ARCHIVE

Some moments never disperse¶

Every photograph here comes from the surviving material. We do not write a story for each one; we record only what we can see.

A note on shooting dates

Most of the surviving photographs carry no specific shooting date. This site does not work backwards from the order of events; it groups the photographs only by the scene that can be recognised.

About these photographs¶

The photographs come from the 微信assets folder in the materials directory. The images have been optimised in size and format for web viewing; no stock imagery was used to stand in for club activities.

Original design drafts and vector materials are in the Design Archive.

List of originals¶

The materials directory Original on-site photographs holds 19 image files in total. The filenames keep their WeChat timestamps, so every single one has a verifiable exact time.

What these times mean

The timestamp in a WeChat filename records the moment the file was processed or saved by WeChat. It is usually close to the shooting time, but it is not the same as the shutter time. This site uses them to summarise the rough period in which activities took place, and does not use them to establish a precise moment of shooting.

What this site does not infer

Not one of the photographs in the surviving material records the photographer, the exact location, or the segment of the event. The last column of the table above is only a summary in time; it does not constitute a determination about the content of the photographs.

On the correspondence between page photographs and originals¶

The photographs on this site's pages are re-encoded versions1 of these originals.

Why the source file is not labelled for each one

Several photographs in the surviving material have exactly the same dimensions (for example 20260421123547, 20260421123548 and 20260421130606 are all 1280 × 853), and after re-encoding the correspondence cannot be determined uniquely from file attributes alone.

This site therefore does not label each page photograph with its original filename — giving a definite answer when the evidence is insufficient is worse than giving none.
