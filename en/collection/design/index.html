Design Archive¶

05 / THE MEMORY COLLECTION · DESIGN ARCHIVE

Sources

The club badge is a parametric design project, not just a few images. The original project is in Badge design project:

  • Badge design project readme — notes on the design process: edit 物理社工牌设计全部模板.svgz in Inkscape, export every page in batch, then use NextGenerator to generate page by page from the fill-in roster, with the output placed in dist
  • source/物理社工牌设计全部模板.svgz — the source project behind all the templates
  • Member group roster — group names, the codes S/N/P/M and colour values
  • Management roster — the roles and English names of the 14 officers
  • Badge vector templates — front and back vector templates for the member groups and the officers
  • material/*.ttc — fonts (the Microsoft YaHei family + BMDOHYEON)

Filter these out and the badge is just an image; keep them and it is a reproducible design.

The original designs in full¶

Those blues, those characters, those carefully arranged details. From club badge to guide signs, keeping them as they were.

Every orbit once pointed at the same place¶

The blue club emblem used here comes from the surviving original artwork. Around it the club built a whole visual system: badges, group marks, guide signs, posters — colour and type all grown from the same emblem.

Data & privacy

This site collects no visitor data. There is no analytics, no advertising, no cookie and no third-party request of any kind. Fonts, styles and scripts are all self-hosted, so any page contacts this site’s domain only. A single light/dark display preference is stored locally by the browser, and is removed when browser data is cleared.
